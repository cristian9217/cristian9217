# Case Study #4: Academic Modality Preferences

The objective is to organize and analyze the collected information to determine 
the preferred academic modalities of students by level and program of study, 
facilitating decision-making and planning more effective educational strategies.

## Description of the data

**Collection date:** January 12 to 16, 2026.

**Total records:** 500 respondents.

| **Variable**     | Type of data |
| ---------------- | ------------ |
| ID 	             | Numeric      |
| Edad	           | Numeric      |
| Municipio	       | Text         |
| Nivel Educativo	 | Text         |
| Programa	       | Text         |
| Modalidad        | Text         |
