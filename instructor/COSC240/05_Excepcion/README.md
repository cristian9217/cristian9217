# COSC 240 - Manejo de Excepciones

Esta carpeta contiene ejercicios de **manejo de expeciones en C++**.

Los ejercicios utilizan ciclos `try`, `catch` y `throw`.

## Ejercicios

- `AgeValidationApp.cpp` - Valida la edad ingresada por el usuario y maneja entradas fuera del rango permitido mediante excepciones. 
- `ArrayIndexApp.cpp` - Demuestra el manejo de excepciones al acceder a posiciones invalidas de un arreglo. 
- `Employee.h` - Define la clase Employee. Se indica sus atributos y metodos relacionados con la información de un empleado.
- `EmployeeApp.cpp` - Prueba la clase `Employee`, mostrando el uso de objetos y manejo de datos de empleados. 
- `FileOpeningException.cpp` - Ejemplo de manejo de excepciones al intentar abrir o acceder a un archivo.
- `InputValidation.cpp` - Valida datos ingresados por el usuario y controla errores mediante excepciones.
- `DivisionExcepcion.cpp` - Maneja excepciones durante operaciones de división, especialmente la división entre cero.
